# 0.4.1：应用图标

替换纯蓝色占位图，统一 Windows 程序、安装器、卸载器、窗口、页眉和 favicon。图标导出包含 16/24/32/48/64/256 像素 ICO，保留生成原图与提示词，见 icon-design.md。

# 0.4.0：批量选择与删除性能

文件页增加至 200 项，跨页保留选择，支持全选当前筛选结果和跨页排除。后端捕获完整选择范围后按 64 项分批执行，提供进度和停止；删除后更新当前列表与全部统计，不再启动整目录扫描。SQLite schema 4 保留原始扫描记录并叠加已知移除版本。具体实现及验证见 bulk-performance.md 和 test-results.md。

# 0.3.0：按用户要求简化

主界面改为“选择文件 → 删除”，去掉八页导航、图表、说明条、审核中转、模式选择和确认文字。筛选、设置和恢复区收起。删除仅授权本次具体选择，不开启后台自动清理；所有底层保护继续生效。此前的完整实现和验证记录如下。
