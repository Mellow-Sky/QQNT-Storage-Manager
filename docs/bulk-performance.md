# 0.4.0 批量选择与删除更新

- 默认 200 项分页，跨页保留手动选择。全选覆盖当前筛选结果，跨页取消勾选作为排除项；改变筛选或扫描会话会清空选择，避免隐藏范围变化。
- 全选通过与文件列表共用的参数化查询捕获具体索引路径，忽略显示页码，保留类型、搜索、大小、日期和风险条件。使用当前任务独占 SQLite 连接的临时表，不向前端传输全部路径或文件详情；每批最多取 64 项，处理前后均不会因分页移动而漏项。
- 删除、失败保留的暂存项与文件版本移除记录在同一应用索引事务提交。schema 4 只新增 file_removals 表，使用路径及完整指纹匹配，避免隐藏同名替换文件。扫描原始记录保留，活动视图扣除已知移除的数量、大小、类型、风险、目录和月份。
- 删除响应携带更新后的当前会话统计，前端就地更新并重新查询当前页，保持会话 ID；不调用 start_scan。媒体读取与执行计划只读会话元信息，避免为每张缩略图或每批计划重复计算统计。
- 整个批量任务持有活动操作锁，逐文件保护与句柄检查不变。批量提供计数进度和停止；完成当前安全检查后停止后续项，结果包含已处理、删除、失败、保留和剩余数量。详细响应限制为前 200 项，完整审计按批次保留。
- QQ 进程在任务开始时检查，运行中快速拒绝整批；执行期间仍保留原有逐文件检查。扫描根与应用索引路径统一 canonical，禁止宽泛授权覆盖本程序索引，避免把持续增长的索引纳入扫描。

自动重扫仅从删除流程移除。用户主动刷新、选择目录和已启用的定时扫描仍按原行为运行；恢复入口仍可重扫。索引视图描述已知变化，不猜测其他程序造成的外部变化。
