# QQNT 兼容性

## 已验证与未知

已验证的是参考仓库实现行为、当前项目的模拟目录和实际文件系统测试。**本次没有读取用户真实 QQ 数据，没有在任何实际 QQNT 版本上完成兼容性验收。** 不能宣称已适配所有新版 QQNT，也不能据候选目录断言缓存安全。

`qqnt-structural @ 1.1.0` 在选中根的直属目录中匹配以下候选之一：`nt_db` 与至少两个 `Pic/Video/Emoji/File` 标记，或 `Pic` 与 `Emoji` 媒体布局（数据库可以位于根外的同级目录），拒绝重解析条目。这是“候选结构匹配”，不是文件语义或恢复性的确认。缺少标记仍允许手动授权的通用文件分析，保持 Unknown/Protected。

| 用户入口 | 范围 | 行为 |
|---|---|---|
| 手动选择 nt_data | 该授权根 | 匹配结构后分析；清理另需显式开关与逐文件审核 |
| 手动选择账号或 Tencent Files | 固定相对候选及一层账号 | 找到结构可验证根则列出多个账号，否则分析所选根 |
| 默认发现 | 当前用户文档/Tencent Files、LocalAppData/Tencent/QQ/UserData | 有限结构探测；没有证据则不返回候选 |
| 修改存储位置、其他 Windows 用户目录 | 用户主动选择且有读取权限 | 不自动跨用户或跨盘搜索 |
| 旧版 Image/Group2、其他/新布局 | 仅手动选择 | 通用只读；不采用旧版缓存语义 |
| symlink/junction/reparse | 不进入 | 计入跳过数量，根含链接时拒绝 |

当前用户文档位置通过 `dirs::document_dir` 使用系统 Known Folder，而非硬编码 `C:\Users\...\Documents`；仍可能遇到云同步重解析目录，此时保守拒绝。支持 Unicode 和 Windows 扩展长度路径的 Rust API；Windows 原生临时文件系统的长路径、中文目录和 junction 用例已通过；原生 WebView2 自检已通过。Explorer 交互定位仍需手动验收。

已加入 `nt_db` 同级布局的匿名夹具测试：默认仅返回 `nt_data` 媒体根，不把范围扩大到数据库；选择该根的“总大小”不包含同级数据库。若用户主动选中更高层目录，则按授权范围统计，所有命中 `nt_db` 和 `Emoji/personal_emoji` 的文件受到拒绝优先保护。候选布局来源与验证界限见 [研究记录](research.md)。

## 媒体

支持常见 PNG/JPEG/GIF/BMP/WebP、MP4/QuickTime/AVI/Matroska 等头特征及扩展名；AVIF/HEIC 等暂按扩展名，不能推断缓存性质。加密 `.dat` 和未识别头保持 Unknown 或保护分类；头特征符合但内部损坏的文件可能为 ReviewRequired，预览解码失败时显示降级信息，不作为低风险证据。缩略图、原件、聊天引用和服务端恢复状态尚无可靠映射。

## 提交兼容问题

记录 QQNT 完整版本、Windows 版本、适配器版本、匿名目录结构、用户选择的入口、候选检测依据、跳过/失败计数。使用新建模拟文件复现，不提交真实聊天记录、账号、图片或媒体原件。新增规则需先以匿名夹具测试，并保持未知布局和数据库保护不能被放宽。

LiteLoaderQQNT 官方仓库于 2026-05-17 归档。已根据官方 manifest v4 与设置页生命周期实现并打包可选入口，Node 边界测试通过，但未在 QQNT 内加载验收。不承诺当前 QQNT 可注入；失败时直接使用独立程序。插件不调用 QQ 私有接口、不删除文件。详见 plugins/liteloader/README.md。

## 清理兼容边界

结构标记只能确认候选根，不证明媒体云端恢复。当前没有 QQ SafeCandidate 规则，自动清理仅回收应用衍生缓存。标准/高级模式可由用户主动审核识别的媒体原件，在 QQ 退出并通过句柄/身份/内容检查后隔离；Unknown、Protected 和未知布局都拒绝。

Windows 本地 NTFS 临时目录已实际验证隔离、恢复不覆盖、永久删除、占用拒绝、只读属性、硬链接及 junction 拒绝、恢复清单导入。UNC 不支持变更。FAT/exFAT、ReFS、云同步目录、杀毒/备份驱动、网络盘及实际 QQ 媒体语义尚未分别验收。

PNG/JPEG/GIF/WebP/BMP/TIFF 图片解码有资源限制；超限、AVIF/HEIC、加密媒体和特殊动画不保证支持。WebView2 H.264 MP4 模拟视频已验证，其他视频编码依赖系统解码器。页面显示文件元数据，视频加载成功后显示实际尺寸与时长，不把修改时间当作消息时间。
