# 0.3.0 简化交互

按用户要求取消主界面的八页导航、图表、说明条、风险模式、审核中转和确认文字。默认直接显示文件；只有四个类型标签。选择目录后自动扫描，删除后自动刷新；日期/大小筛选与设置默认折叠。

文件列表中的“删除”是明确的本次选择授权，直接完成永久删除。后台仍先生成精确文件计划、计算摘要、验证授权/保护/QQ 退出/占用/句柄身份，逐项暂存并删除。界面不暴露这些内部步骤。扫描不写 QQ 数据，后台自动清理的开关和原件审核边界不被直接删除请求改变。旧审核 API 保留供兼容使用，主界面不调用它们。

最终删除失败且已暂存的文件显示为恢复区保留项，不能报告为成功释放；用户在设置中直接恢复，无需启用全局自动清理。受保护、未知或变化文件拒绝删除。所有正向破坏性测试只使用专用模拟临时目录。

浏览器交互测试验证：选择文件后点击一次“删除”只发送一次 delete_files，没有弹窗、模式、plan_cleanup、execute_cleanup 或 enable_cleanup 调用。此项使用明确标为 MOCK 的 IPC 测试夹具，未加入产品运行代码。Windows 后端单元测试在临时目录核验实际永久删除、保护/数据库/未知拦截、恢复和全局自动清理保持关闭；只在单元测试中注入 QQ 退出检查。生产命令固定使用真实进程检查，前端无覆盖入口。
